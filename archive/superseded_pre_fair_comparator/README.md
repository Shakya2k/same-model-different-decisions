# Superseded comparator run

An earlier version of Experiment 03 gave expected-exposure ranking access to true economic exposure while the estimated cost-aware policies used noisy estimates. That was not a fair comparison for the question under study.

After equalizing the information set so that C_est, D1_est, and D2_est share the same estimated economic exposure, the apparent high-noise reversal disappeared.

This directory keeps the original unequal-information run for methodological provenance and auditability. It is superseded by the fair-comparator Experiment 03 implementation.

Do not use results in this directory to support the project's publication claims.
